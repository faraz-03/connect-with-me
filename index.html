Saving your contact

iPhone: Open the contact file and choose Create New Contact or Add to Existing Contact, if shown. If it downloads instead, open the file. You may need to open this page in Safari.

Android: Open the downloaded .vcf file and select Contacts. If it doesn't open, use the Contacts app's Import from file option.

Your phone asks you to confirm. Saving again may create a duplicate; saved contacts do not update automatically.
